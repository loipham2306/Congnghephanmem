# 🏥 Website Quản Lý Phòng Khám

Dự án phát triển phần mềm: Hệ thống Website Quản lý phòng khám giúp tối ưu hóa quy trình đặt lịch, khám chữa bệnh và quản lý thông tin bệnh nhân, bác sĩ.

### 🛠️ Công nghệ sử dụng

Dự án được xây dựng dựa trên các công nghệ sau:
* **Frontend:** ReactJS
* **Backend:** NodeJS, ExpressJS
* **Database:** PostgreSQL

---

### ✨ Chức năng chính (Dự kiến)

* **Đối với Bệnh nhân:** Đăng ký/Đăng nhập, đặt lịch khám trực tuyến, xem lịch sử khám bệnh.
* **Đối với Bác sĩ:** Quản lý lịch hẹn, cập nhật hồ sơ bệnh án, kê đơn.
* **Đối với Quản trị viên (Admin):** Quản lý tài khoản (bác sĩ, nhân viên, bệnh nhân), quản lý dịch vụ phòng khám, thống kê doanh thu.
